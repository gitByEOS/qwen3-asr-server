# D-ASR-003 静音归并后再解析

## 背景与目标

| 字段 | 说明 |
|---|---|
| 要解决的问题 | 整段音频一次 generate，CPU 上每个字都要再看全片。固定秒数切开会把一个字切成两截，后半截被听成新词 |
| 业务/技术背景 | mp4 等已由 ffmpeg 转成 16kHz 单声道 wav。模型只吃这个采样率。官方按音频切片推送只支持带显卡的服务 |
| 目标边界 | 先扫静音，归并后再切人声，然后逐段解析并拼接文本。不产出时间点，不引入语音区间检测模型 |

## 关联功能

[asr](../features/asr.md)

## 架构设计

### 用法与接口

```text
16kHz wav
 → 扫描静音，得到原子段 [{s, e, d}, ...]
 → 只合并相邻原子段，使每组时长贴近 30 秒
 → 每组从第一段的 s 切到最后一段的 e，组内气口留在音频里
 → 逐段解析
 → 文本顺序拼接，每段结束推出已有全文
```

仍是一次 HTTP 请求。30 秒是分组目标，不是硬上限；原子段不再往下切，没有静音可切时保持整段。

### 核心思路

**先按气口得到原子段，再只合并相邻段，让每组贴近 30 秒。** 不在字中间下刀。组内的气口留在送去解析的音频里。

### 数据

| 名字 | 含义 |
|---|---|
| 原子段 | `{s, e, d}`，s 起点秒，e 终点秒，d = e - s |
| 组 | 若干个相邻原子段。组时长 = 最后一段的 e − 第一段的 s |
| 目标时长 | 30 秒 |

以 20ms 帧扫描 RMS < 300 的静音，短于 0.35 秒的不作为边界。静音之间的非空有声区间形成原子段，数量由输入决定；分组按下方装箱规则计算，不依赖特定样本的段数。

纯静音不形成原子段；当前实现没有原子段时仍保留完整 wav 交给引擎，并非跳过整段静音。切片按取整后的起止采样位置之差读取，避免浮点时长截断丢采样。

### 装箱

只合并相邻原子段，不打乱顺序，不拆开一段。在全部合法切法里，选各组 `(组时长 − 30)²` 之和最小的一种。组数 n 是算出来的，不是事先指定。

代价相同则组数更少；仍相同则最短的那组更长。当前实现的代价比较容差为 `1e-9`。

从右往左填表。`best[i]` 是从第 i 个原子段到结尾的最小代价。`best[段数] = 0`。对每个起点 i、每个终点 j：

```text
组时长 = 原子段[j-1].e - 原子段[i].s
代价 = (组时长 - 30)² + best[j]
```

取最小代价并记录 j，再从 0 沿记录切出各组。上传体积不能限制原子段数量，完整枚举是二次规模；不能假设始终只有十几段。

当前采用精确剪枝：组长达到目标后，本组代价随终点单调不减，后缀代价非负；若本组代价已超过当前最优总代价加 `1e-9`，后续终点不可能更优，可停止枚举。容差内的平局候选仍保留，不以近似贪心替代最优目标，也不承诺任意输入均为线性耗时。

例：时长 10、12、9、11、8，且段与段之间没有额外气口。贪心会收成 31 秒和 19 秒。装箱收成 22 秒和 28 秒，两边都更靠近 30 秒。原子段本身长于 30 秒时不再切开。

### 协同

```text
L3 预处理
  ffmpeg 转 16kHz 单声道
  扫描原子段 → 装箱成贴近 30 秒的组 → 按组切 wav
       ▼
L2 编排
  按时间顺序逐段调用 L5
  每段文本接到上一段后面再交出
       ▼
L1
  一次请求，结果区看到拼接后的全文

空闲卸载
  30 秒一次心跳
  模型在内存里，且没有转写占着锁
  连续 5 次都这样 → 卸掉模型
  下次转写再冷启动
```

### 关键设计点

| 设计点 | 是什么 | 为什么这么定 |
|---|---|---|
| 先扫描再装箱 | 原子段来自静音，组来自装箱 | 切点仍在气口上，组时长贴近 30 秒 |
| 过短静音取消 | 短于 0.35 秒的气口不切原子段 | 过碎的气口会切开音节 |
| 无静音不硬切 | 没有原子段边界就整段解析；单段长于 30 秒也不拆 | 硬切会把字切成两截 |
| 组内留气口 | 音频从组的 s 切到组的 e | 拼文件时丢掉气口会把两句粘成一句 |
| 逐段解析 | 每组只看自己的音频 | 缩短单次生成要看的长度 |
| 逐段独立 | 每组结束关闭生成流并清理生成上下文，模型权重继续复用 | 后一组不继承前一组的解码状态 |
| MLX 生成保护 | 每组默认最多生成 2048 tokens；尾部内容连续重复 8 次时提前结束 | 无结束标记或重复解码不能长期占住单飞锁 |
| 文本拼接 | 段与段直接相连 | 不产出时间轴 |
| 空闲卸载 | 30 秒心跳，连续 5 次无转写就卸模型 | 解放内存，下次使用再加载 |

## 被排除方案

| 方案 | 排除原因 |
|---|---|
| 固定 30 秒切 | 切点会落在字中间 |
| 语音区间检测模型 | 要的是静音区间，不是时间点 |
| 无静音时按上限硬切 | 仍会把字切成两截 |
| 官方按音频切片推送 | 这台机器没有可用显卡 |

## 不变量与约束

| 类型 | 内容 |
|---|---|
| 不变量 | 原子段边界只来自静音；组只由相邻原子段合并 |
| 不变量 | 段的顺序与原音频一致，文本按这个顺序拼接 |
| 不变量 | 分组使 `(组时长 - 30)²` 之和最小 |
| 约束 | 纯静音不单独成段；组内气口仍留在送去解析的音频里 |
| 约束 | 没有可切静音时只解析一次 |
| 约束 | 2048 tokens 是 MLX 每组的默认生成上限，不是整个音频的文本上限；无静音的超长连续语音可能触及上限 |
| 约束 | 转写进行中不计空闲；卸掉之后下次转写重新加载 |
| 约束 | 非空有声原子段不因时长短而删除；切片使用取整后的起止采样位置之差 |
| 约束 | 清理切片失败仍释放单飞锁，错误继续向调用方报告 |
