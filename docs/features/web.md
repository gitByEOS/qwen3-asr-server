# web

## 概述

| 字段 | 说明 |
|---|---|
| 业务目标 | 局域网打开一个网页即可上传音视频并看到转写文本，可开关人声增强 |
| 边界 | L1 单页；无账号、不持久化、不下载 SRT、不显示准确率分数 |
| 关键概念 | 内嵌 HTML、同进程 API、忙碌锁、enhance 开关 |

## 功能清单

| 状态 | F 编号 | 可观测结果（主体在触发条件下产生） | design |
|---|---|---|---|
| ✓ | F-WEB-001 | 用户打开 GET / 时看到转写页，含文件选择、enhance 开关与提交 | D-ASR-001 |
| ✓ | F-WEB-002 | 用户在网页上传合法音视频并提交后，页面展示接口返回的 `text` | D-ASR-001 |
| ✓ | F-WEB-003 | 转写进行中用户再次提交时页面不发出第二次请求，并保持忙碌提示 | D-ASR-001 |
| ✓ | F-WEB-004 | 接口返回 `error` 时页面展示该错误文案，不展示空白成功态 | D-ASR-001 |
| ✓ | F-WEB-006 | 用户切换 enhance 后提交，请求带上对应该开关的 on 或 off，页面展示响应里的 `enhance` | D-ASR-001 |
| ✓ | F-WEB-007 | 用户打开页面时看到拖入区，脚本处理 drag-over 与 drop 文件 | D-ASR-001 |
| ✓ | F-WEB-008 | health.missing 非空时页面展示缺少项，页面仍可打开 | D-ASR-001 |
